.. _advanced-features:

Advanced Features
-----------------

This section is for advanced users, i.e. people who already know how to use the engine and are already familiar
with the basic features of the OpenQuake engine. If you have just started on your journey of using
and working with the OpenQuake engine, this section is probably NOT for you. Beginners should study the previous
sections first.

If you are running large calculations, i.e. calculations that cannot be run because they run out of memory, they
fail with strange errors or they just take too long to complete, read :ref:`large-calculations` first: it contains
the techniques to reduce an impossible calculation to a feasible one.
